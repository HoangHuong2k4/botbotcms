Bắt đầu sử dụng

Hệ thống cung cấp API cho phép bạn tự động hóa việc xem kho, kiểm tra số dư và tự động xuất tài khoản để bán trên bot của riêng bạn. Bạn mua với giá sỉ (tùy chiết khấu) và tự định giá bán lẻ.

  1. Liên hệ Admin Phạm Hoàng Hương để đăng ký làm Cộng Tác Viên (CTV).
  2. Sau khi được duyệt, bạn sẽ được cấp một API Key (dạng DLR_XXXXX...).
  3. Nạp tiền vào tài khoản của bạn trên hệ thống.
  4. Gắn API Key vào header của mọi request gửi lên server theo hướng dẫn bên dưới.

Xác thực (Authentication)

Mọi request BẮT BUỘC phải gửi kèm API Key trong header:

X-API-KEY: DLR_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

Nếu thiếu header hoặc key sai, hệ thống sẽ trả về lỗi HTTP 401 hoặc HTTP 403.

GET /api/v1/dealer/stock

Xem tồn kho, danh sách sản phẩm và giá sỉ hiện tại của bạn. Bạn nên gọi API này để làm menu trên bot.

curl -H "X-API-KEY: DLR_xxxxx" https://domain.com/api/v1/dealer/stock

Response 200:

{ "success": true, "dealer": "Tên CTV", "balance": 500000, "products": { "1": { "name": "Tài khoản loại A", "price": 35000, "stock": 50, "type": "account" } } }

💡 Tip: Nên Cache kết quả của API này từ 30-60 giây trên server của bạn, không nên gọi liên tục mỗi khi có khách xem menu.

GET /api/v1/dealer/balance

Kiểm tra số dư hiện tại trong ví của CTV.

curl -H "X-API-KEY: DLR_xxxxx" https://domain.com/api/v1/dealer/balance

POST /api/v1/dealer/buy

Mua hàng tự động. Hệ thống sẽ tự trừ tiền trong ví và trả về thông tin tài khoản.

Tham số (JSON) Bắt buộc Mô tả
product_key Có ID của sản phẩm (lấy từ API Stock)
qty Có Số lượng mua (1-100)
order_code Không Mã đơn hàng tùy chỉnh của bạn (để dễ đối soát)
curl -X POST https://domain.com/api/v1/dealer/buy \ -H "X-API-KEY: DLR_xxxxx" \ -H "Content-Type: application/json" \ -d '{"product_key": "1", "qty": 1, "order_code": "BOT-12345"}'

Response Thành Công:

{ "success": true, "product": "1", "items": [ "user1@gmail.com|pass1", "user2@gmail.com|pass2" ], "qty": 2, "total_charged": 70000, "balance_remaining": 430000, "order_code": "BOT-12345" }

Bảng Mã Lỗi

Mã HTTP Lỗi Mô tả / Hướng xử lý
401 Thiếu header X-API-KEY Cần truyền header xác thực
403 API key không hợp lệ Key sai, bị khóa hoặc bạn không có quyền CTV
400 Lỗi tham số Thiếu product_key hoặc qty không đúng định dạng
200 Không đủ số dư Trả về {"success": false, "error": "Cạn số dư"}. Nạp thêm tiền.
200 Hết hàng Trả về {"success": false, "error": "Hết hàng"}.
