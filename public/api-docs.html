Telehub API Documentation

Tài liệu hướng dẫn kết nối API dành cho Cộng Tác Viên (Đại lý)

1. Hướng dẫn Xác thực (Authentication)

Tất cả các API Endpoints đều yêu cầu phải xác thực bằng cách gửi kèm API Key vào Header của Request với từ khóa X-API-KEY. Bạn có thể lấy API Key từ hệ thống quản trị của nền tảng. 

GET /api/v1/telehub/user HTTP/1.1
Host: cms.cataishop.shop
X-API-KEY: DLR_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GET https://cms.cataishop.shop/api/v1/telehub/user

5. Các Mã Lỗi (HTTP Status Codes)

  • 200 OK: Request thành công.
  • 400 Bad Request: Sai dữ liệu đầu vào hoặc không đủ điều kiện mua (Hết tiền, hết hàng).
  • 401 Unauthorized: Không tìm thấy X-API-KEY hoặc Key không hợp lệ.
  • 404 Not Found: Không tìm thấy sản phẩm.
  • 500 Internal Server Error: Lỗi máy chủ, Transaction thất bại.
